## ЧАСТЬ 1. ПРОБЛЕМЫ ИЗ РИСЁРЧЕЙ

### 1.1 Из «Исследование детей: Как маркетплейсы встроены в повседневную культуру потребления»

Ключевые инсайты (реконструированы из контекста исследования и смежных данных):

| # | Проблема | Что происходит |
|---|---|---|
| P1 | **Маркет не участвует в этапе «хочу»** | Дети и подростки формируют желание в TikTok/Instagram/YouTube, а на Маркет приходят только с готовым запросом. Discovery-момент теряется |
| P2 | **Барьер оплаты = родительский контроль** | Ребёнок находит товар, но не может купить самостоятельно — нет механизма «попросить родителя» прямо из карточки/выдачи |
| P3 | **Избранное как «парковка желаний»** | Дети используют «Избранное» не для покупки, а как вишлист — но возможности поделиться с родителем нет (или она скрыта) |
| P4 | **Выдача не визуальна для молодой аудитории** | Молодёжь привыкла к feed-формату (видео, образы, образ жизни). Стандартная сетка карточек «скучна» — не вовлекает, не вдохновляет |
| P5 | **Нет teen-контента/тренды** | Маркет не показывает «что сейчас трендово у сверстников», хотя это ключевой драйвер покупки у подростков |
| P6 | **Нет встроенного сравнения с конкурентами для ребёнка** | Дети проверяют цену на WB/Ozon в соседней вкладке — Маркет теряет их на этапе финального выбора |

## ЧАСТЬ 3. НОВЫЕ ИДЕИ

### 🔍 ПОИСКОВАЯ ВЫДАЧА (SERP)

---

#### Идея 1. «Почему сейчас» — Authentic Context Strip

**Проблема:** P13, P22 — пользователь не понимает «почему купить здесь сейчас», а таймеры воспринимаются как манипуляция.

**Концепция:**  
Под ценой в карточке — тонкая строка с **реальным контекстом**, а не фейковым дедлайном:
- «156 человек смотрят сейчас» (реальный трафик)
- «Осталось 3 штука на складе в Москве» (реальный остаток)
- «Цена снизилась за последние 7 дней» (без таймера, но с историей цены)
- «С Плюсом ваша цена: 890 ₽» (персональная цена с кэшбэком)

**Механика:** бекенд-флаги реального спроса/остатка; не показывается, если нет реальных данных (anti-fake guard).

**Метрики:** конверсия в заказ, % «добавил в корзину» vs «ушёл», жалобы на «навязчивость».

---

#### Идея 2. «Мы дешевле» — Price Confidence Badge

**Проблема:** P20, P21 — пользователи уходят на WB/Ozon проверить цену.

**Концепция:**  
Маркет уже агрегирует предложения — значит, у нас есть данные по конкурентам. Для товаров, где Маркет действительно дешевле (с учётом кэшбэка Плюс), показывать в карточке выдачи:
- Бейдж **«Выгоднее, чем на WB»** с суммой разницы
- Разворачивается в «почему»: «На WB — 2 490 ₽, здесь — 1 890 ₽ с Плюсом»

**Guard:** показывать ТОЛЬКО когда реально дешевле. Ни одной «нечестной» метки → доверие.

**Монетизация:** возможна «Гарантия лучшей цены» как Плюс-перк.

---

#### Идея 3. «Собери образ/комплект» — Set Completion на SERP

**Проблема:** P9, P10 — пользователь ищет «кроссовки Nike», но не знает, что к ним подойдёт; маркет теряет cross-sell.

**Концепция:**  
После 3–4 карточки в выдаче по запросам типа «одежда», «кроссовки», «товары для кухни» — показывать горизонтальный блок:

```
┌──────────────────────────────────────────────┐
│  ✦ Маркет AI подобрал образ с этим товаром   │
│  [Кроссовки] + [Носки] + [Спортивные штаны]  │
│  Весь образ: 4 200 ₽  [Посмотреть образ →]  │
└──────────────────────────────────────────────┘
```

**Вариант для интерьера:** «Подобрать к дивану → кофейный столик, плед, торшер».

**Монетизация:** кросс-категорийный GMV + новый рекламный формат «попасть в образ» для брендов.

---

#### Идея 4. «Что говорят» — Video Review Snippets на SERP

**Проблема:** P17, P19 — пользователи уходят на YouTube за обзорами.

**Концепция:**  
Для топовых категорий (электроника, бьюти, гаджеты) — в карточке выдачи маленький превью видео-обзора (15 сек loop без звука). Тап → открывается в полный экран с кнопкой «Купить».

**Источники контента:**
- UGC от покупателей Маркета (уже оставляют отзывы с фото — расширить до видео)
- Партнёрские обзоры (инфлюенсеры как новый рекламный формат)
- AI-нарезка из длинных обзоров (short clip extraction)

**Монетизация:** «Видео-буст» — продавец платит за показ видео-обзора в выдаче (новый ad-format).

### 🏠 ГЛАВНАЯ СТРАНИЦА (Homepage)

---

#### Идея 5. «Доброе утро / Добрый вечер» — Контекстная Главная

**Проблема:** P8, P15, P16 — главная одинаковая в 7 утра и 22 вечера, не учитывает контекст.

**Концепция:**  
Главная адаптируется к **времени дня + lifecycle-стадии пользователя**:

| Время / Контекст | Заголовок блока | Контент |
|---|---|---|
| Утро, будни | «Доброе утро — что нужно сегодня?» | Быстрая доставка сегодня, продукты, кофе |
| Вечер пятницы | «Выходные начинаются» | Досуг, хобби, кино дома |
| После просмотра электроники | «Продолжить поиск» | Continuation feed по категории |
| Неделя до Нового года | «Подарки — ещё не поздно» | Тематическая «срочная» подборка |
| Новый пользователь | «Знакомьтесь — Маркет» | Onboarding discovery, лучшие категории |

**Механика:** правила + ML по времени суток / сезону / последней сессии.

**Метрика:** click-through с Главной, сессии из Главной → заказ.

---

#### Идея 6. «Вдохновение» — Discovery Feed на Главной

**Проблема:** P7, P8, P9 — Маркет пропускает этап вдохновения; пользователь уходит на Pinterest/TikTok.

**Концепция:**  
Новый блок на Главной (под хедером, между «Популярные категории» и «Рекомендации»):

```
┌──────────────────────────────────────────────────┐
│  ✦ Идеи для тебя сегодня                        │
│                                                  │
│  [Образ: лёгкое лето]  [Балкон мечты]  [Офис ] │
│  [Подарок другу-геймеру]  [Уют в спальне]       │
│                                                  │
│  Каждая карточка = тематическая подборка 8-12   │
│  товаров, собранная AI + редакторами             │
└──────────────────────────────────────────────────┘
```

**Принцип:** не «товары», а **намерения / образы жизни** → пользователь идентифицирует себя → попадает в тематическую выдачу.

**Источник контента:** AI-подборки из имеющегося каталога + редакторские тематики (еженедельно).

**Связь с вирусностью:** такие образы расшариваются — встроить «Поделиться подборкой».

---

#### Идея 7. «Вишлист → Родителю» — Детский режим / Семейный шопинг

**Проблема:** P2, P3, P4, P5 — дети и подростки хотят покупать, но ограничены оплатой; маркет не работает с этим сегментом.

**Концепция:**  
**«Семейный шопинг»** — легковесная фича на главной и в карточке:

1. **Детская подборка** на Главной: блок «Популярно у подростков» (возрастная персонализация для аккаунтов с профилем ребёнка в Яндекс ID)
2. **«Попросить у родителя»** — кнопка на карточке товара → товар добавляется в общий «Список желаний», родитель получает уведомление/email
3. **«Вишлист на день рождения»** — создаёт ребёнок, делится ссылкой с семьёй (замена gift registry)
4. **Семейный счёт** — родитель устанавливает месячный лимит для ребёнка, ребёнок самостоятельно оплачивает в рамках лимита

**Монетизация:** расширение аудитории, рост GMV детского/подросткового сегмента, семейные подписки Плюс.

---

#### Идея 8. «Трендит сейчас» — Viral Trend Strip

**Проблема:** P5, P17, P18 — молодая аудитория ориентируется на тренды; Маркет не показывает их.

**Концепция:**  
Горизонтальная полоска в верхней части Главной (под строкой поиска):

```
🔥 Трендит прямо сейчас:  [Станок для ногтей]  [Эко-бутылка 1л]  [Виброплатформа]  [Stanley cup dupe]
```

**Источники трендов:**
- Рост поисковых запросов на Маркете (собственные данные)
- Социальные сигналы (что ищут + «сохраняют» пользователи)
- AI-мониторинг упоминаний товаров в публичных пространствах

**Частота обновления:** ежедневно / несколько раз в день.

**Guard:** не показывать товары с низким рейтингом или плохим фулфилментом.

---

#### Идея 9. «Следующий шаг» — Intent Continuation

**Проблема:** P11, P12 — пользователь прерывается, уходит «подумать», теряется.

**Концепция:**  
При возврате на Главную — персональный блок «Вы искали → продолжить»:

```
┌─────────────────────────────────────────────────────┐
│  👋 Привет! Вы смотрели пылесос Dyson V15           │
│  Он ещё в наличии. Цена упала на 500 ₽ с вашего    │
│  последнего визита.                                  │
│  [Посмотреть] [Добавить в корзину] [Другие варианты]│
└─────────────────────────────────────────────────────┘
```

**Варианты триггеров:**
- Цена снизилась с момента просмотра
- Остался последний экземпляр
- Похожий товар дешевле появился

**Принцип:** только реальные триггеры → доверие (не фейковый urgency).

### 🔍 ДОПОЛНИТЕЛЬНЫЕ ИДЕИ ДЛЯ ПОИСКОВОЙ ВЫДАЧИ (SERP — расширенный блок)

---

#### Идея 10. «Поиск по проблеме» — Problem-First SERP

**Проблема:** P10 — пользователь не всегда знает название товара; он знает **проблему**.

**Концепция:**
Когда запрос детектируется как «проблемный» («чем убрать ржавчину», «что делать если скрипит дверь», «как не потеть летом»), выдача перестраивается:

```
Запрос: «чем убрать жёлтые пятна с белой рубашки»

┌──────────────────────────────────────────────────┐
│  ✦ Маркет AI нашёл решение                       │
│  «Для этого подойдут пятновыводители и замачивание│
│   с оксигенольным порошком»                       │
│                                                  │
│  [Пятновыводитель] [Кислородный отбеливатель]    │
│  [Средство для замачивания]                       │
└──────────────────────────────────────────────────┘
Ниже — обычная выдача с нужными товарами
```

**Механика:** NLU классификатор «проблемных» запросов + AI-перефразировка в продуктовые категории.

**Метрика:** конверсия на проблемных запросах (сейчас они конвертятся хуже всего), уход со страницы.

---

#### Идея 11. «Фильтр по отзывам» — Review-Attribute Filter

**Проблема:** P15 — пользователь не может отфильтровать по тому, что важно ему (не по характеристикам, а по впечатлениям от использования).

**Концепция:**
Новый тип фильтра в фильтр-панели — **«Что говорят покупатели»**. AI извлекает топовые атрибуты из отзывов по каждой категории:

| Запрос | Атрибуты из отзывов |
|---|---|
| «Пылесос» | 🔇 Тихий · 🔋 Держит заряд · 🐾 Хорош для шерсти · ⚡ Мощный |
| «Кроссовки» | 👟 Не натирает · 📐 Точномерит · ☁️ Лёгкие · 🌧 Водоотталкивающие |
| «Матрас» | 😴 Не скрипит · 🌡 Не жаркий · 💪 Жёсткий · ☁️ Мягкий |

Тап на атрибут = переранжирование выдачи по товарам, где это упоминается positively в отзывах.

**Differentiator:** WB показывает атрибуты из отзывов в карточке — но не как фильтр выдачи. Здесь мы делаем это раньше, на уровне SERP.

**Метрика:** adoption нового фильтра, конверсия vs стандартные фильтры.

---

#### Идея 12. «Для кого ищете?» — Intent Micro-Quiz в SERP

**Проблема:** P14, P15 — запрос неоднозначен по контексту; пользователь не хочет вручную вбивать уточнения.

**Концепция:**
Для запросов с неоднозначным **получателем** или **сценарием** — после строки поиска появляется 1 вопрос с 3–4 вариантами, который моментально переранжирует выдачу:

```
Запрос: «шампунь»

┌─────────────────────────────────────────┐
│  Для кого шампунь?                       │
│  [Для себя] [Для ребёнка] [Для питомца] │
│  [Пропустить]                            │
└─────────────────────────────────────────┘
```

```
Запрос: «наушники»

┌─────────────────────────────────────────────────┐
│  Как будете использовать?                        │
│  [Для спорта] [Для работы/офиса] [Для дома + TV]│
│  [Для звонков]                                   │
└─────────────────────────────────────────────────┘
```

**Ключевое отличие от чипов «Давайте уточним»:** не «добавь слово к запросу», а «расскажи контекст» → персонализация ранжирования, а не смена запроса.

**Метрика:** response rate на квиз, конверсия после ответа vs пропустил.

#### Идея 13. «97% довольны» — Satisfaction Prediction Badge

**Проблема:** P22 — пользователь не доверяет рейтингу 4.8⭐ (много фейков); нужен более честный сигнал доверия.

**Концепция:**
AI-бейдж, основанный не на среднем рейтинге, а на **поведенческих паттернах после покупки**:

```
[✓ 94% возвращаются за повторной покупкой]
[✓ Низкий % возвратов: 2%]
[✓ Рекомендуют друзьям: 89%]
```

Бейдж появляется только при достаточном количестве данных (anti-fake guard). Тап → объяснение, как считается.

**Differentiator:** рейтинг можно накрутить — поведенческие паттерны (возвраты, повторные покупки) накрутить нельзя.

**Метрика:** CTR карточек с бейджем, конверсия, доверие (NPS).

#### Идея 14. «Сегментированная выдача» — Intent Sections

**Проблема:** P10 — один запрос покрывает несколько совершенно разных намерений → выдача «каша».

**Концепция:**
Когда запрос однозначно покрывает ≥2 разных Intent-сегмента, выдача разбивается на **явные секции**:

```
Запрос: «чемодан»

═══════════════════════════════
  ✈️ Для ручной клади (до 55×40×20 см)
═══════════════════════════════
  [карточка] [карточка] [карточка] →

═══════════════════════════════
  🧳 Большой (для сданного багажа)
═══════════════════════════════
  [карточка] [карточка] [карточка] →
```

```
Запрос: «детская кроватка»

═══ Новорождённый (0–6 мес) ══
═══ Для подросшего (1–5 лет) ══
```

**Механика:** ML-классификация запросов с multi-intent + группировка товаров по intent-кластерам.

**Метрика:** скролл-глубина, CTR по секциям vs стандартная выдача, конверсия.

#### Идея 15. «История цены мини» — Price Timeline в карточке выдачи

**Проблема:** P20 — пользователь не знает, «нормальная» ли цена сейчас; уходит искать историю на сторонних сервисах.

**Концепция:**
Под ценой в карточке — микро-спарклайн (4–5 точек) истории цены за последние 30 дней + подпись:

```
1 490 ₽  📉 -320 ₽ за месяц  [мин за 30 дн: 1 390 ₽]
         ▁▃▅▃▁  ← спарклайн
```

Варианты сообщений:
- «Цена на минимуме за 30 дней» → честный urgency
- «Цена выше обычного» → честность → доверие
- «Стабильная цена» → нет суеты

**Метрика:** CTR, конверсия, % «добавил в избранное для ожидания снижения».

#### Идея 16. «Без этого» — Negative Filter (Исключающий фильтр)

**Проблема:** P15 — пользователь хочет исключить определённые атрибуты, но интерфейс это не поддерживает.

**Концепция:**
В фильтр-панели — возможность добавить «не хочу» критерии:

```
Фильтры →  [+ Без мешка]  [+ Не Dyson]  [+ Не Китай]  [+ Без глютена]
```

Технически: negative фильтр по атрибутам каталога + бренду + стране производства.

**Use cases:**
- «Пылесос — НЕ мешочный»
- «Протеиновый батончик — без сахара, без глютена»
- «Кроссовки Nike — не China production»

**Метрика:** adoption фильтра, конверсия тех, кто использовал «не хочу», удовлетворённость выдачей.

#### Идея 17. «Похожие — дешевле» — Alternative Nudge

**Проблема:** P12, P20 — пользователь несколько раз просматривает дорогой товар, но не покупает. Маркет его теряет.

**Концепция:**
Триггер: пользователь просмотрел карточку 2+ раза без добавления в корзину. При следующем поисковом запросе в той же категории — вставляем блок в выдачу:

```
┌──────────────────────────────────────────────────────┐
│  Вы смотрели: Dyson V15 [22 990 ₽]                   │
│  Похожие по характеристикам, дешевле:                 │
│  [Miele Triflex] 16 990 ₽ · [Rowenta] 12 490 ₽      │
│  ✦ AI: «У Miele схожая мощность и автономность»      │
└──────────────────────────────────────────────────────┘
```

**Guard:** только если реально похожи по key specs — никаких «дешёвых аналогов» с другими характеристиками.

**Монетизация:** органический anti-exit + «попасть в блок альтернатив» как рекламный формат.

## ЧАСТЬ 6. БЫСТРЫЙ ПИТЧ (ФОРМАТ «1 СЛАЙД»)

### Идея-кандидат № 1: «Authentic Context Strip» (SERP)

> **Проблема:** Urgency на выдаче воспринимается как манипуляция → пользователь не верит, не конвертируется.  
> **Решение:** Показывать реальный контекст рядом с ценой: реальный остаток, реальный спрос, реальная история цены.  
> **Метрика:** конверсия search→order +X%  
> **Сложность:** M (бекенд-флаги уже существуют, UI — минимален)

### Идея-кандидат № 2: «Price Confidence Badge» (SERP + Homepage)

> **Проблема:** ~30% пользователей уходят проверить цену на WB/Ozon — и не возвращаются.  
> **Решение:** Для товаров, где Маркет реально дешевле (с учётом Плюса), показывать бейдж «Выгоднее, чем на WB» с суммой разницы.  
> **Метрика:** снижение exit rate, рост конверсии  
> **Сложность:** M (данные конкурентов есть/можно парсить)

### Идея-кандидат № 3: «Discovery Feed» (Homepage)

> **Проблема:** Маркет не присутствует в этапе вдохновения — пользователь формирует желание на TikTok/Pinterest, а не на Маркете.
> **Решение:** Блок тематических AI-подборок на Главной — «образы», «сеты», «идеи» вместо сухих категорий.
> **Метрика:** новые сессии из Главной, cross-category GMV, время на сайте
> **Сложность:** L (нужна editorial + AI-пайплайн для сборки образов)

#### Идея 18. «Один сигнал» — Smart Reason-to-Buy Badge

**Источник:** [«Исследование "Причины купить"»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/issledovanie-prichiny-kupit), [«Зелёнка и промо-механики»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/zelenka-i-promo)

**Проблема:** На карточке в выдаче — 3–5 зелёных плашек одновременно («Выгодно», «−30%», «Быстрая доставка», «Бестселлер»). Пользователь их перестаёт замечать. Зелёнка обесценилась.

**Концепция:**
Вместо россыпи плашек — **один умный бейдж**, который AI выбирает индивидуально для каждого товара × каждого пользователя на основе сигнала, наиболее значимого именно сейчас:

| Ситуация | Smart Badge |
|---|---|
| Цена снизилась за 7 дней | «Цена упала» |
| Товар часто берут повторно | «Покупают снова» |
| Отзывы говорят о долговечности | «Служит годами» |
| Доставка завтра для данного пользователя | «Приедет завтра» |
| Первая покупка в категории | «Хит категории» |

**Принцип:** максимум **один** бейдж на карточку в выдаче. Не два, не три — один, самый значимый.

**Метрика:** CTR карточек с умным бейджем vs текущим количеством плашек; A/B «много плашек» vs «один сигнал».

#### Идея 19. «Понятная скидка» — Discount Transparency Layer

**Источник:** [«Зелёнка и промо-механики»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/zelenka-i-promo), [«Исследование FOMO-скидки»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/issledovanie-fomo-skidki-na-poiskovojj-vydache-mar)

**Проблема:** Пользователи скептичны к скидкам — подозревают, что «было 1000, стало 700» — это искусственное завышение цены перед акцией.

**Концепция:**
Тап на плашку «−30%» → мини-попап с историей цены:

```
┌─────────────────────────────────────────────┐
│  Скидка честная?                             │
│                                             │
│  Цена 3 месяца назад: 999 ₽                 │
│  Текущая цена: 699 ₽                        │
│  Минимальная цена за год: 649 ₽             │
│                                             │
│  ✓ Скидка реальная — цена действительно    │
│    снизилась по сравнению с историческим   │
│    уровнем                                  │
└─────────────────────────────────────────────┘
```

**Guard:** если цена была искусственно завышена перед акцией → показывать честно: «Минимум за год — 589 ₽». Пользователь доверяет и остаётся на Маркете.

**Дифференциатор от конкурентов:** WB/Ozon не раскрывают историю цены. Это сильный trust-сигнал.

**Метрика:** конверсия на акционных товарах, доверие (NPS), % «вернулся в эту категорию».

#### Идея 20. «Раздели прямо в выдаче» — Split-Pay Nudge на SERP

**Источник:** [«Количественное исследование строки сплита в сниппете»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/kolichestvennoe-issledovanie-stroki-splita-v-snipp), [«Оплата и Сплит»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/5856a5dcc125/payment-and-split)

**Проблема:** Пользователь видит товар за 15 000 ₽ и откладывает покупку («дорого»). Возможность сплита есть, но узнаёт о ней только на странице оплаты — уже после того, как решил не брать.

**Концепция:**
В карточке выдачи для товаров выше порога (например, >5 000 ₽) — строка под ценой:

```
15 490 ₽   или 3 × 5 163 ₽/мес — без переплат
```

Тап → уточнение условий (bottom sheet), без ухода из выдачи.

**Механика:** уже есть бекенд-логика сплита; нужно только вытащить расчёт на уровень выдачи.

**Метрика:** конверсия на дорогих товарах (>5К), использование сплита из SERP vs из карточки, AOV.

#### Идея 21. «Совместный вишлист» — Shared List от выдачи

**Источник:** [«Избранное на Маркете. 2024»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/izbranoe-na-markete), [«Списки в Избранном»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/spiski-v-izbrannom)

**Проблема:** Пользователи используют Избранное как «парковку для совместного обсуждения» (покупка с партнёром, семья, подарок) — но поделиться списком из выдачи нельзя без входа в раздел Избранного.

**Концепция:**
Кнопка «Добавить в список» прямо в выдаче (рядом с «в корзину») — с возможностью сразу создать **именованный шаринг-список**:

```
[В корзину]  [♥ В список ▼]
              → [Список «Кухня»]
              → [Список «Подарок Маше»]
              → [+ Новый список] → сразу шаринг-ссылка
```

Шаринг-ссылка → получатель открывает список, видит товары, может добавить свои «голоса» (лайки) без регистрации.

**Use cases:** покупка кухонной техники с партнёром; подарок коллективом; шопинг с мамой.

**Метрика:** % списков, к которым были приглашены другие; конверсия из шаринг-списка в заказ; GMV из совместных покупок.

#### Идея 22. «Эксперт говорит» — Curator Review на SERP

**Источник:** [«Публичные профили»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/publichnye-profili), [«Публичные профили на Озон»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/5856a5dcc125/ugc-2/public-profiles), [«Отзывы на карточках товаров»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/otzyvy-na-tovary)

**Проблема:** Пользователи доверяют «эксперту» — человеку с историей и специализацией — больше, чем анонимным отзывам. На Ozon есть публичные профили; на Маркете пока нет видимой кураторской роли.

**Концепция:**
В карточке выдачи по специализированным категориям (электроника, спорт, косметика) — мини-блок с цитатой от верифицированного куратора:

```
┌──────────────────────────────────────────────┐
│  👤 Алексей (1 234 отзыва · Гаджеты)         │
│  «Лучший выбор для новичков в беговой        │
│   дорожке — тихий мотор и простой экран»     │
└──────────────────────────────────────────────┘
```

Куратор = пользователь с историей покупок в категории + верифицированными отзывами + публичным профилем. Не инфлюенсер, не продавец.

**Монетизация (опционально):** «Стать куратором категории» — статусная механика (не платная). Кураторы получают ранний доступ к акциям.

**Метрика:** CTR карточек с кураторской цитатой, конверсия, % «посмотрел профиль куратора».

#### Идея 23. «Куплю в подарок» — Gift Mode на SERP

**Источник:** [«Исследование сценария подарка в AI-чате»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/5856a5dcc125/diskaveripoiskrekomendacii2023/issledovanie-scenarija-podarka-v-ai-chate-marketa), [«Мультикатегорийный выбор в AI-чате»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/issledovanie-multikategorijjnogo-vybora-v-ai-chate)

**Проблема:** Подарочный сценарий — один из крупнейших по GMV — плохо поддерживается в обычной выдаче. Пользователь пишет «подарок маме», попадает в выдачу и теряется: нет контекста «для кого», «на какой повод», «какой бюджет».

**Концепция:**
Детектор подарочного запроса («подарок», «в подарок», «для мамы», «на день рождения») → выдача перестраивается в **Gift Mode**:

```
Запрос: «подарок маме на 8 марта»

┌─────────────────────────────────────────────┐
│  🎁 Режим подарка                           │
│  Получатель: мама · Повод: 8 марта          │
│  Бюджет: [до 1 000] [1-3К] [3-7К] [7К+]   │
└─────────────────────────────────────────────┘

Выдача: тематические подборки +
«Завернуть в подарочную упаковку» на каждой карточке +
«Добавить открытку» в корзине
```

**Отличие от AI-чата:** Gift Mode работает прямо в SERP без перехода в чат. AI-чат = глубокий диалог; Gift Mode = быстрая адаптация выдачи.

**Метрика:** конверсия на подарочных запросах, AOV (подарки дороже), % добавления упаковки/открытки.

### Источник: «Дефолтный опыт 2024» + «Почему удаляют приложение»

---

#### Идея 24. «Помоги мне найти себя» — Taste Profile Onboarding в выдаче

**Источник:** [«Дефолтный опыт на Маркете. 2024»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/default-experience-market-2024), [«Почему удаляют приложение»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/app-market)

**Проблема:** Новый пользователь приходит → видит «холодную» выдачу без персонализации → рекомендации нерелевантны → разочарование → удаление приложения. Онбординга нет.

**Концепция:**
Для новых пользователей (первые 3 сессии) — в выдаче по любому запросу появляется **одноразовый блок прокачки вкуса**:

```
┌─────────────────────────────────────────────────┐
│  Помогите нам настроить Маркет для вас           │
│  Что вам важнее в товарах? (тап на 2-3 варианта)│
│                                                 │
│  [Цена] [Качество] [Быстрая доставка]           │
│  [Надёжный бренд] [Экологичность]               │
│                                          [OK →] │
└─────────────────────────────────────────────────┘
```

Ответы → мгновенный re-rank выдачи + сигнал для всей будущей персонализации.

**Принцип:** не отдельный онбординг-флоу перед первым поиском, а **встроенный в момент поиска** — пользователь уже видит, что выдача меняется в ответ на его выбор.

**Метрика:** completion rate блока, retention D7/D30, CTR персонализированной vs дефолтной выдачи.

### Источник: «Особенности покупки уценённых и б/у товаров»

---

#### Идея 25. «Найди дешевле — б/у» — ReCommerce Slot в выдаче

**Источник:** [«Особенности покупки уценённых и б/у товаров»](https://wiki.yandex-team.ru/market/ux/baza-issledovanii-b2b/5856a5dcc125/buying-discounted-and-used-goods)

**Проблема:** Часть пользователей открыта к б/у и уцененным товарам, но видит их отдельно (если вообще видит). В SERP нового товара нет никакого сигнала «есть дешевле — б/у».

**Концепция:**
В стандартной выдаче — небольшая вставка после 4–5 карточки:

```
┌──────────────────────────────────────────────┐
│  💰 Есть дешевле — уценка и б/у             │
│  [iPhone 14] 42 990 ₽  Новый               │
│  [iPhone 14] 29 490 ₽  Уценённый (отл.сост)│
│  [iPhone 14] 24 990 ₽  Б/у (продавец ★4.9) │
│  Посмотреть все б/у →                        │
└──────────────────────────────────────────────┘
```

**Guard:** показывать только при реально проверенных состояниях товара; продавец б/у должен иметь рейтинг ≥4.5.

**Метрика:** CTR блока, конверсия на уцененных товарах, % пользователей, которые «переключились» с нового на б/у, общий GMV категории.
