# Врезка «Давайте уточним» — дизайн-спека для Figma

Фича помогает пользователю сузить широкий поисковый запрос прямо внутри выдачи,
не требуя ручного перепечатывания. Построена на данных исследования SRPA-226.

Дата: 2026-06-25. Платформа: mobile-first (iOS app), 375 pt ширина.
Токены, типографика и сетка — общие с `YANDEX_MARKET_AI_SEARCH_FIGMA_SPEC.md`.

---

## 1. Контекст и проблема (зачем нужно)

**Данные из исследования широких запросов (SRPA-226):**
- Широкие запросы = ~11% от всех запросов Маркета; 17,5% пользователей делают хотя бы один широкий запрос в месяц.
- Только **10–16%** пользователей самостоятельно сужают запрос.
- **88%+ сужений** происходят через ручной ввод нового запроса — фильтры и GPT-задачи суммарно дают <12%.
- Конверсия в заказ у тех, кто **сузил** запрос, в **2–2,7 раза выше**, чем у тех, кто остался на широком.
- **39%** пользователей сужают в первую минуту, но ~47% тратят более 2 минут → есть окно для подсказки.

**Вывод:** нужна явная врезка, которая предлагает готовые уточнения прямо в выдаче,
пока пользователь ещё скроллит первые ряды карточек — до 5-го ряда (доскролл ~55%).

**Куда обычно сужают (приоритет вариантов):**
1. Товарные запросы: характеристики → бренд → функционал/предназначение.
2. Категорийные запросы: бренд → конкретный продукт.
3. Брендовые запросы: модель (в технике) → продукт/категория (в фэшне).

## 2. Концепт врезки

Компактный горизонтально-скроллируемый блок, который появляется **после 2-го ряда** выдачи
на широких запросах. Содержит:

1. **Заголовок-вопрос** «Давайте уточним?» — предлагает действие, не утверждает.
2. **Чипы-уточнения** — готовые варианты сужения, сгруппированные по смыслу.
3. **Опциональная кнопка «Ввести самому»** — для тех, кто знает точный запрос.
4. **Закрыть (×)** — dismissed-состояние; блок убирается до конца сессии.

Блок **не блокирует органику**: выдача видна сверху и снизу.
Тап по чипу = немедленный поиск с выбранным запросом (не переход в чат).

## 4. Компонент NarrowQueryWidget (C9)

### Анатомия

```
┌─────────────────────────────────────────────────────────┐  ← radius/lg, bg/narrow
│ ✦ Давайте уточним?                              [×]     │  ← header row
│                                                         │
│ [Чугунная 26 см] [Вок] [IKEA] [До 3000 ₽] [С крышкой]  │  ← horizontal scroll
│                                                         │
│ [ Ввести самому → ]                                     │  ← опциональный footer
└─────────────────────────────────────────────────────────┘
```

### Параметры auto-layout
- Контейнер: `vertical`, gap 12, padding 16, radius lg.
- Левый бордер: 2px solid `border/narrow`.
- Фон: `bg/narrow`.
- Header row: `horizontal`, space-between, align center.
- Chip row: `horizontal`, gap 8, overflow scroll, no-wrap.

### Header (slot)
- Иконка ✦ (`accent/ai`, 16×16) + текст «Давайте уточним?» (`type/body`, semibold, `text/primary`).
- Кнопка [×] (`icon/close`, 20×20, `text/secondary`); tap → dismissed state.

### Chip variants (C9a — NarrowChip)
Auto-layout: horizontal, gap 4, padding 6/12, radius pill.

| variant | bg | text | использование |
|---|---|---|---|
| `default` | `chip/default-bg` | `chip/default-text` | обычные варианты сужения |
| `ai` | `chip/ai-bg` | `chip/ai-text` | чипы, предложенные AI-моделью |
| `active` | `chip/active-bg` | `chip/active-text` | нажатый/выбранный чип |

AI-чип дополнительно: микро-иконка ✦ слева (12×12, `accent/ai`).

### Footer (опциональный)
Ссылка-кнопка «Ввести самому →» (`type/caption`, `accent/ai`, underline none).
Показываем когда чипов > 5 или категория = Электроника/Компьютерная техника (там сужают в конкретные модели, которые сложно угадать).

### States (Variants в Figma)

| state | описание |
|---|---|
| `loading` | skeleton header + 4 chip-skeleton, bg/subtle, shimmer animation |
| `default` | нормальное отображение с чипами |
| `expanded` | показаны чипы 2-й строки (тап «Ещё варианты») |
| `dismissed` | компонент hidden (height 0, opacity 0); восстанавливается при новом запросе |
| `empty` | нет данных (новый хид/редкий запрос) → компонент не рендерится вовсе |

## 5. Типология чипов по категориям

Порядок чипов внутри блока — по приоритету из исследования:

### Товарные запросы (чемодан, сковорода, пылесос)
```
[Чипы характеристик] → [Чипы бренда] → [Чипы функционала]

Пример: запрос «сковорода»
→ [Чугунная 26 см ✦] [С крышкой] [Для индукции] [IKEA] [Tefal] [До 2000 ₽]
```

### Категорийные запросы (женская одежда, садовая мебель)
```
[Чипы бренда] → [Чипы конкретного продукта]

Пример: запрос «обувь женская»
→ [Dior ✦] [Nike] [Кроссовки] [Сабо] [До 5000 ₽] [Размер 38]
```

### Брендовые запросы (samsung, befree)
```
В технике: [Чипы моделей] → [Чипы продуктов]
В фэшне:   [Чипы продуктов] → [Чипы характеристик]

Пример: запрос «samsung»
→ [Galaxy S24 ✦] [Смартфоны] [Телевизоры] [До 30 000 ₽] [Наушники]
```

## 6. Позиционирование в выдаче

```
[SearchBar]
[FilterBar]                  ← sticky
─────────────────────────────
[ProductCard row 1]
[ProductCard row 2]
═════════════════════════════  ← после 2-го ряда
[NarrowQueryWidget]          ← ВРЕЗКА «Давайте уточним?»
═════════════════════════════
[ProductCard row 3]
[ProductCard row 4]
...
```

**Логика показа:**
- Показывать только если запрос определён как широкий (бекендовый флаг `is_broad_query=true`).
- Не показывать, если пользователь уже кликнул хотя бы на 2 карточки (значит, выдача устраивает).
- Не показывать повторно в той же сессии после dismissed.

## 7. Экраны / фреймы для Figma

Страница `02 · Narrow Query`. Фреймы 375×812 (iPhone):

- SearchBar с запросом «сковорода».
- FilterBar.
- 2 ряда ProductCard(skeleton).
- NarrowQueryWidget(loading) с shimmer-чипами.
- 2 ряда ProductCard(skeleton).

### F11 — SERP: врезка с чипами (главный экран)
- SearchBar: «сковорода».
- FilterBar: активен чип «Выгодно».
- 2 ряда ProductCard (обычные карточки, без AI-бейджей — простая выдача).
- **NarrowQueryWidget(default):**
  - Заголовок «Давайте уточним?» + [×].
  - Чипы: [Чугунная 26 см ✦] [Вок] [С крышкой] [Tefal] [Для индукции] [До 2000 ₽].
  - Чипы ✦ = ai variant (фиолетовые), остальные = default (серые).
  - Footer «Ввести самому →».
- 2 ряда ProductCard ниже.

### F12 — SERP: чип выбран → поиск
- SearchBar обновился: «сковорода чугунная 26 см».
- FilterBar — без изменений.
- NarrowQueryWidget **скрыт** (dismissed после выбора).
- Новая выдача с более релевантными карточками.
- Toast снизу: «Запрос уточнён» (2 сек, затем уходит).

### F13 — SERP: dismissed (закрыт пользователем)
- Показываем [×] pressed.
- Widget анимируется: height → 0, opacity → 0 (smart animate).
- Выдача смыкается плавно.

### F14 — SERP: «Ввести самому» (bottom sheet)
- Тап на «Ввести самому →» → открывается мини-шит с SearchBar в фокусе.
- Шит: 40% высоты, blur backdrop.
- В строке поиска: текущий запрос «сковорода» + курсор в конце.
- Suggestion chips: «+ чугунная», «+ вок», «+ tefal» (быстрые добавки к запросу).

### F15 — Empty state / новый хид
- NarrowQueryWidget **не рендерится**.
- Выдача без врезки — обычная сетка.
- Примечание в Figma-аннотации: «Компонент hidden когда `empty` state».

### F16 — Dark mode (F11 в тёмной теме)
- Переключение через Figma Variables режим Dark.
- `bg/narrow` в Dark = `#2A2500` (тёмный жёлтый-тёплый).
- `border/narrow` = `#FFCC00` (без изменений).

## 8. Состояния и крайние случаи

| Ситуация | Поведение |
|---|---|
| Нет данных для чипов (редкий запрос) | `empty` state → компонент не рендерится |
| Запрос на узбекском / транслит | Чипы с нераспознанным языком не показываются (фильтрация на беке) |
| Брендовый запрос → чип другого бренда | Запрещено на уровне логики (из проблем витрины в SRPA-226) |
| Чип с опечаткой | Не попадает в список (нормализация на беке) |
| Пользователь уже применил фильтр | Врезка не показывается (фильтр = уже сужение) |
| Ошибка загрузки чипов | `loading` → `empty` через 1,5 сек timeout; компонент скрывается |
| A11y | Каждый чип = role=button, aria-label «Уточнить запрос: [текст чипа]»; контраст ≥ 4.5:1 |

## 9. Прототип (Figma interactions)

- **F11** → tap чип [Чугунная 26 см] → **F12** (SearchBar обновляется, widget исчезает, выдача меняется; smart animate).
- **F11** → tap [×] → **F13** (widget collapse; smart animate height+opacity).
- **F11** → tap «Ввести самому →» → **F14** (slide up 40% sheet).
- **F14** → tap suggestion chip «+ чугунная» → **F12** (sheet уходит, выдача обновляется).
- **F14** → submit SearchBar → **F12** (аналогично).
- **F12** → toast «Запрос уточнён» через 200ms → auto-dismiss через 2000ms.

## 10. Метрики для трекинга

| Метрика | Цель |
|---|---|
| CTR врезки (хотя бы 1 чип тапнут) | > 15% от сессий с широкими запросами |
| Конверсия в заказ после тапа на чип | x2 vs контроль (без врезки) |
| Dismissed rate (закрыли [×]) | < 30% — если выше, пересмотреть позицию/качество чипов |
| «Ввести самому» rate | мониторинг: если > 40%, значит чипы нерелевантны |
| Доля сессий без ручного перепечатывания | должна расти (88% → меньше) |

## 11. Порядок сборки в Figma (чек-лист)

1. Добавить токены `color/bg/narrow`, `color/border/narrow`, `color/chip/*` в Variables.

4. Собрать **F11** (главный экран с врезкой): скопировать F2 из основной спеки, вставить C9 между 2-м и 3-м рядами.

6. Настроить прототип по §9.
7. Добавить аннотации (Figma Annotations) к C9: логика показа, условия скрытия.
