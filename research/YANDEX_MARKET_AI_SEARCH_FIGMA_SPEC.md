# Маркет AI Выдача — дизайн-спека для Figma

Фича-кандидат на рост выручки Яндекс Маркета. Документ построен так, чтобы по нему можно
было собрать кликабельный прототип в Figma без дополнительных вопросов: есть токены,
анатомия компонентов с авто-лейаутом, размеры фреймов, экраны по состояниям и сценарии
прототипа.

Дата: 2026-06-25. Платформа референса: mobile-first (iOS app), 360–375 pt ширина.

---

## 1. Проблема и возможность (зачем это деньги)

**Что есть сейчас на Маркете**
- Выдача = одна объединённая карточка модели (плюс продавцы внутри), фильтры в дропдауне,
  фильтр «Выгодно», фильтры по цвету, рейтинг с коэффициентом качества отзыва.
- Маркет AI (YandexGPT 5 Pro) существует, но как **отдельный чат** — пользователь должен
  выйти из выдачи, спросить, вернуться. Агент не участвует в моменте принятия решения.
- Раздел «Спешл» с AI-образами — отдельная витрина, не связана с поиском по запросу.

**Что делают конкуренты (это уже гигиена, не преимущество)**
- Wildberries: характеристики из отзывов прямо в карточке выдачи; поиск по фото с выбором
  конкретного объекта + текстовое уточнение (~1.7 млн польз./день); пересказ отзывов ИИ.
- Ozon / Lamoda: поиск по фото (у Ozon без выбора объекта).

**Тренды 2026, которые конвертируются в деньги**
- Intent-/conversational-поиск (запрос фразой, а не ключевыми словами).
- Мультимодальный/визуальный поиск: +70% объёма запросов, конверсия +20–30%, AOV до +48%.
- Гиперперсонализация в реальном времени (>56% покупателей ждут персональных предложений).
- Agentic commerce: ИИ-агент как активный участник покупки; новый канал трафика и конверсии.
- Trust-guardrails: люди пока не доверяют полной автономии ИИ → нужна прозрачность.

**Возможность.** Маркет AI сильнее как продукт, чем «чат сбоку». Если встроить агента прямо
в выдачу, он влияет на конверсию и AOV в момент решения — а это ровно те метрики, на
которых маркетплейс зарабатывает. Плюс появляется **новый рекламный инвентарь** (см. §3).

## 2. Концепт фичи: «Маркет AI Выдача»

Агентный слой поверх обычной поисковой выдачи. Четыре связанных блока:

1. **AI-саммари запроса (Intent Answer).** Над выдачей — короткий ответ агента на запрос
   фразой: что важно учесть, 2–3 готовых варианта под разные приоритеты («дешевле»,
   «баланс», «топ»). Раскрывается в полноценный чат-уточнение, не уводя со страницы.
2. **Умные бейджи на карточке (Review-to-spec).** Под товаром — 2–4 буллета, извлечённых
   ИИ из отзывов/характеристик: «тихий», «держит заряд 2 дня», «маломерит». Тег
   достоверности использует существующий коэффициент качества отзыва.
3. **Визуальный + мультимодальный поиск.** Камера/фото в строке поиска → распознавание с
   **выбором конкретного объекта на фото** (догоняем и обгоняем WB) + текстовое уточнение
   («такое же, но дешевле / в чёрном»).
4. **Полка сравнения (Compare Tray).** Свайпом добавляешь в сравнение прямо из выдачи; ИИ
   делает таблицу различий и вердикт «кому какой подойдёт».

Объединяющий принцип: **агент не уводит из выдачи, а ускоряет решение внутри неё.**

## 3. Модель монетизации (как именно приносит прибыль)

Выручка маркетплейса = ставки/реклама продавцов + комиссия с оборота (зависит от
конверсии и AOV). Фича бьёт в оба источника.

| Механика | Что монетизируем | Тип дохода |
|---|---|---|
| **Promoted AI-рекомендация** | 1 слот в AI-саммари помечен «Спонсор» — продавец платит за попадание в ответ агента | Новый ad-инвентарь (CPM/CPC), высокий intent |
| **Boost в полке сравнения** | Продавец платит за то, чтобы его модель попала в авто-подбор для сравнения | Новый ad-инвентарь |
| **Визуальный поиск → ставки** | Фото-запросы дают «горячий» трафик; ставки за топ в визуальной выдаче | Расширение текущих ставок |
| **Конверсия и AOV** | Меньше ухода на сторонние сайты за сравнениями → выше конверсия и средний чек | Рост комиссии с GMV |
| **Маркет Плюс-перк (опц.)** | Расширенный AI-разбор/«личный байер» как перк подписки Плюс | Подписочный ARPU |

**Гард-рейлы доверия (обязательно для метрик и для trust):**
- Спонсорские слоты всегда видимо помечены «Спонсор».
- У AI-вывода всегда есть «почему» (источник: отзывы / характеристики) и кнопка 👍/👎.
- Нейтральность подбора (как заявлено у Маркет AI) сохраняется в органической части.

## 4. Метрики успеха

- **Северная звезда:** конверсия search→order на сессиях с AI-выдачей vs контроль.
- Драйверы: CTR по AI-саммари, доля сессий с визуальным поиском, использование сравнения,
  AOV, доля «ушёл на сторонний сайт» (должна падать).
- **Деньги:** новый ad-revenue со слотов «Спонсор», eCPM визуальной выдачи.
- **Guardrail:** доля 👎 на AI-ответах < X%; жалобы на «навязанную рекламу»; latency саммари.

## 5. Дизайн-токены (Figma Variables / Styles)

Создать как **Variables** в коллекции `market/*`, режимы Light/Dark.

### 5.1 Цвет
```
color/bg/base            #FFFFFF      // фон страницы
color/bg/subtle          #F5F5F7      // секции, скелетоны
color/bg/ai              #F3F0FF      // подложка AI-блоков (лёгкий лавандовый)
color/bg/ai-strong       #E9E3FF
color/border/subtle      #E7E7E9
color/text/primary       #21201F      // фирменный «почти чёрный» Маркета
color/text/secondary     #6B6B70
color/text/inverse       #FFFFFF
color/accent/brand       #FFCC00      // жёлтый Маркета (CTA-заливка)
color/accent/brand-ink   #21201F      // текст на жёлтой кнопке
color/accent/ai          #7B61FF      // фиолетовый = «ИИ», отделяет от органики
color/accent/price       #F5305C      // цена/скидка
color/accent/price-bg    #FFE9EF
color/state/success      #2DB67C      // «Выгодно», «в наличии»
color/state/sponsor      #9A8C00      // подпись «Спонсор» (приглушённый)
```

### 5.2 Типографика (шрифт: YS Text / системный SF как фолбэк)
```
type/display     22 / 28  bold     // заголовок AI-саммари
type/title       17 / 22  semibold // название товара
type/body        15 / 20  regular
type/caption     13 / 16  regular  // бейджи, мета
type/micro       11 / 14  medium   // «Спонсор», теги достоверности
```

### 5.3 Радиусы, отступы, тени
```
radius/sm 8   radius/md 12   radius/lg 16   radius/pill 999
space: 4 / 8 / 12 / 16 / 20 / 24   (база 4)
elevation/card:  0 1 3 rgba(0,0,0,.08)
elevation/sheet: 0 -2 16 rgba(0,0,0,.12)
grid: контент-паддинг 16; гэп между карточками 12
```

## 6. Компоненты (анатомия + авто-лейаут)

Каждый — Figma Component с вариантами (Property → значения). Auto-layout указан как
`направление, gap, padding`.

### C1. SearchBar (мультимодальный)
- Auto-layout: horizontal, gap 8, padding 8/12, radius pill, bg `bg/subtle`.
- Слоты: `icon/search` · `input (text)` · `icon/camera` · `icon/mic`.
- Variants: `state = default | typing | image-attached`.
- В `image-attached`: слева мини-превью фото (32×32, radius sm) + chip «убрать ✕».

### C2. AISummaryCard (Intent Answer) — ядро фичи
- Контейнер: vertical, gap 12, padding 16, radius lg, bg `bg/ai`, лев. бордер 2px `accent/ai`.
- Header: иконка-искра ✦ (accent/ai) + «Маркет AI» (caption) + chip «бета».
- Body: 1–2 строки ответа фразой (`type/body`).
- 3 чипа-приоритета (horizontal, gap 8, pill): «Подешевле» / «Баланс» / «Топ».
- 3 мини-карточки-рекомендации (см. C3-mini), одна может быть `sponsored`.
- Footer: «Уточнить у Маркет AI →» (открывает C7) + 👍/👎.
- Variants: `state = loading(skeleton) | answered | empty`.

### C3. ProductCard (выдача)
- Контейнер: vertical, gap 8, padding 12, radius md, bg base, elevation/card.
- Анатомия сверху вниз:
  1. Image 1:1 (radius sm) + оверлей-иконка «в сравнение ⇄» (top-right) + бейдж «Выгодно» (top-left, success).
  2. Price row: `accent/price` крупно + старая цена зачёркнута + «−24%».
  3. Title (`type/title`, 2 строки, ellipsis).
  4. Rating row: ★ 4.7 · «312 оценок» (caption, secondary).
  5. **AI-бейджи (новое):** 2–3 chips `bg/ai`/`accent/ai` текст: «тихий», «держит 2 дня».
     У каждого — крошечный тег достоверности (точка success/secondary).
  6. CTA: «В корзину» (заливка brand, текст brand-ink, radius pill, full-width).
- Variants: `layout = grid | list`, `sponsored = true|false`, `inCompare = true|false`.
- При `sponsored=true`: микро-подпись «Спонсор» (`micro`, state/sponsor) под рейтингом.

### C3-mini. RecChip (внутри AISummaryCard)
- Horizontal: thumb 40×40 · (title 1 строка + price) · стрелка.
- Variant `sponsored=true` → метка «Спонсор».

### C4. FilterBar (sticky)
- Horizontal scroll, gap 8: кнопка «Фильтры ⚙» + быстрые pill-чипы
  («Выгодно», «Доставка завтра», цвет, бренд). Активный чип — заливка `text/primary`/inverse.

### C5. CompareTray (полка сравнения)
- Прилипает снизу при ≥2 товарах. Horizontal: 2–4 thumb (48×48, ✕ на каждом) +
  кнопка «Сравнить (3)» (brand). Тянется вверх в C6.

### C6. CompareSheet (bottom sheet)
- Header: «Сравнение · Маркет AI». 
- AI-вердикт-блок (bg/ai): «Для игр — A, для долгой батареи — B».
- Таблица различий: строки-характеристики, столбцы-товары; различия подсвечены.
- CTA по каждому столбцу: «В корзину».

### C7. AIChatSheet (уточнение, не уводит из выдачи)
- Bottom sheet 92% высоты. Лента сообщений + быстрые подсказки-чипы.
- Ответы ИИ рендерят те же C3-mini; «Показать в выдаче» возвращает на SERP с
  применёнными фильтрами из диалога.

### C8. VisualSearchSheet (поиск по фото)
- Фото на весь фрейм + **детектированные объекты** = тапаемые рамки/точки.
- Выбранный объект → нижняя панель: «Найти похожее» + поле текст-уточнения
  («дешевле», «в чёрном»). Это ключевой обгон WB: объект + текст в один заход.

## 7. Экраны / фреймы для Figma

Собрать страницу `01 · AI Search` с фреймами 375×812 (iPhone). Минимальный набор:

1. **F1 — SERP: loading.** SearchBar(typing) · AISummaryCard(loading skeleton) ·
   FilterBar · 4× ProductCard(skeleton).
2. **F2 — SERP: answered (главный экран).** SearchBar с запросом
   «тихий пылесос для квартиры с котом до 20000» · AISummaryCard(answered) с 3 чипами и
   3 реками (1 sponsored) · FilterBar · сетка ProductCard с AI-бейджами (1 sponsored).
3. **F3 — SERP с активной полкой сравнения.** То же + CompareTray внизу (3 товара).
4. **F4 — CompareSheet.** Таблица + AI-вердикт.
5. **F5 — AIChatSheet.** Диалог-уточнение → кнопка «Показать в выдаче».
6. **F6 — VisualSearchSheet: захват/распознавание.** Фото с объектами.
7. **F7 — VisualSearchSheet: объект выбран + текст-уточнение → результаты.**
8. **F8 — Empty / Low-confidence.** Когда ИИ не уверен: честный месседж + обычная выдача
   («Не уверен в подборе — вот все варианты»). Trust-guardrail.
9. **F9 — Dark mode** вариант F2 (проверка токенов).

## 8. Состояния и крайние случаи

- **Loading:** скелетоны (bg/subtle), саммари ~600–900 мс; не блокирует органику —
  выдача рендерится сразу, AI-саммари «доезжает» сверху.
- **Low confidence:** не выдумывать; показать F8.
- **Нет отзывов для бейджей:** скрыть AI-бейджи, не плейсхолдерить.
- **Sponsored:** всегда видимая метка; не более 1 спонсор-слота в саммари и не чаще
  каждой N-й карточки в органике.
- **Offline / ошибка ИИ:** деградация до обычной выдачи без AI-блока (graceful).
- **A11y:** контраст текста ≥ 4.5:1; AI-фиолетовый только как акцент, не как текст по белому.

## 9. Прототип (Figma interactions)

- F2 → tap чип «Подешевле» → пересортировка реков (smart animate).
- F2 → tap «Уточнить у Маркет AI» → F5 (slide up).
- F5 → «Показать в выдаче» → F2 с применёнными фильтрами.
- F2 → tap иконку камеры → F6.
- F6 → tap объект на фото → F7 (выбранный объект подсвечен).
- F2 → tap «в сравнение ⇄» на 2+ карточках → появляется CompareTray (F3).
- F3 → tap «Сравнить» → F4 (sheet up).
- Везде 👎 на AI → тост «Спасибо, учтём» (сигнал в guardrail-метрику).

## 10. Порядок сборки в Figma (чек-лист)

1. Variables: цвет (Light/Dark), число (space/radius), типографика → Text Styles.
2. Базовые компоненты: SearchBar, ProductCard (с вариантами), AISummaryCard.
3. Составные: FilterBar, CompareTray/Sheet, AIChatSheet, VisualSearchSheet.
4. Собрать F2 (главный), затем клонировать в остальные состояния.
5. Прототип-связи по §9. Dark-mode фрейм переключением режима переменных.
