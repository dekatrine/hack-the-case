# Локальный запуск Hack the Case

Открыть терминал в корне репозитория и выполнить:

```bash
npm install
npm run dev
```

Команда самостоятельно проверяет backend на порту 8001. Если он уже запущен и отвечает на `/health`, используется существующий процесс. Если нет — запускается Python/FastAPI из `backend/.venv` с отслеживанием только `backend/app`. Если порт занят другим сервисом, ищется следующий свободный порт. Vite настраивает proxy автоматически, так что вручную указывать `VITE_API_BASE_URL` больше не нужно.

Перейти по адресу, который выводит Vite (обычно `http://localhost:5173/`). В адресе `http://localhost:5173/api/config` должен открываться JSON настроек генерации; `http://localhost:5173/health` возвращает `{"status":"ok"}`.

Для нового клона, когда `backend/.venv` отсутствует:

```bash
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cd ..
npm run dev
```

Проблемы:
- **Не удалось запустить Python** — установить зависимости в `backend/.venv`.
- **Нет свободного порта** — освободить занятые порты либо установить `HTC_BACKEND_PORT=8100`.
- **Запрос к AI возвращает 502** — проверить серверные переменные YandexGPT; `/health` и `/api/config` не требуют ключа и должны работать без него.
- **Нужен только frontend** — использовать `npm run dev:frontend`. Тогда proxy по умолчанию направляет `/api` на порт 8001.
- **Нужно переопределить Python** — `HTC_PYTHON=/path/to/python npm run dev`.

Не загружайте реальные ключи API в GitHub. Локальные кейсы хранятся в браузере; их удаление не требуется.
